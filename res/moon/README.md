# Moon color map

`lroc_color_poles_1k.jpg` is the unmodified 1024×512 color map from the [NASA CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/).

Credit: NASA's Scientific Visualization Studio. Visualizer: Ernie Wright (USRA); scientist: Noah Petro (NASA/GSFC). The map uses LROC Wide Angle Camera data.

[Original image](https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_poles_1k.jpg). NASA SVS makes this material available for reuse under its [media-use policy](https://svs.gsfc.nasa.gov/help/).
