# Image codecs

Unmodified runtime sources, loaded locally only when a TIFF is decoded:

- UTIF.js 3.1.0: https://github.com/photopea/UTIF.js — `UTIF-LICENSE` (MIT).
- pako 1.0.11: https://github.com/nodeca/pako — `pako-LICENSE` (MIT/Zlib).

Files were obtained from the matching pinned npm package distributions. No runtime CDN is required.
